**The port is a solo project.** tsatria03 is its only author. There are no code contributors.

**Why:** the dev's standing rule, taken from the reference material in `user/` on 2026-10-22.

**How to apply:**
- Commits have tsatria03 as author, with no `Co-authored-by:` line for any person. Only the Claude attribution line is added ([[feedback_git_commits]]).
- The credits name tsatria03 for the port and Luke Charman for the original game, as its bundle id and the dissertation in `game/data/text/` name him ([[project_original_findings]]). The original's cast and other credits are in its own credits recording, and are cited from it if the port lists them.
- Never credit, mention or assume any other contributor in notes, docs, comments or the changelog.
- If the dev ever says someone has joined, or names someone to credit, update this note first.
